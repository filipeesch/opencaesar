## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| flow input → suppliedFountains | A fountain must only supply clean water when its tile truly carries flow; a disconnected fountain must never be reported supplied |
| fountain activity → house water | `resolveFountainActivity` (active = supplied && staffed) is the single gate between network/workers and clean-water coverage — bypassing it must be impossible in the model |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-04-03 | Spoofing | fountain reports supply while disconnected | high | mitigate | block/repair tests assert suppliedFountains only on truly flowing tiles; isolated tile never supplied |
| T-04-04 | Tampering | fountain stays lit without water/workers | high | mitigate | go-dark tests for both `supplied:false` and `staffed:false` drop coverage to none; determinism test locks repeatability |
