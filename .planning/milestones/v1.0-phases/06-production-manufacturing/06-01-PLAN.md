<threat_model>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Extraction footprint → deposit | A site must only produce when its footprint actually sits on the required deposit (resourceType/terrain); a mis-placed site must never yield output |
| Workshop output → destination | A finished load may only move to a destination that accepts the good and has capacity; no load may be discarded or teleported when no destination exists |
| Blocked states → stocks | missing_input / output_full / blocked / no-destination must never alter or destroy held input/output units |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Tampering | deposit requirement bypass | high | mitigate | satisfiesDeposit/canExtract gate every extraction tick; mismatched/absent deposit yields false and is asserted by extraction.test.ts |
| T-06-02 | Repudiation | destination validity | high | mitigate | porterDestination returns null over invalid candidates; pipeline test asserts stock rises exactly by the ported load (conservation) |
| T-06-03 | Repudiation | warehouse fallback | medium | mitigate | explicit fallback test: busy workshop → nearest valid warehouse; no goods dropped |
| T-06-04 | Tampering | silent goods destruction | high | mitigate | blocked-state no-loss tests assert byte-identical stocks across every blocked branch |
| T-06-05 | Privacy | none (pure model) | low | accept | no secret/user data in the model layer |
</threat_model>
