### CR-01: `palatine` is not in `TYPE_SECTOR` — permanently de-staffed and deactivated

**Files modified:** `src/sim/labor.ts`, `tests/unit/labor-sectors.test.ts`
**Commit:** `4a69cd9`
**Applied fix:** Mapped `palatine: 'commerce'` in `TYPE_SECTOR` (alongside forum/senate, per the review suggestion). Added two regression tests: a pure-helper test (`buildLaborSectors` folds the palace's 40 workers into commerce `needed`) and a runner-level test that REAL-places a labor-connected palatine — 45 houses reach the 900-pop `govPalatineThreshold` unlock gate, treasury funded past the 3000 cost — and asserts `workersAssigned === workersRequired`, `active === true`, commerce `needed >= 40`, and `assignedWorkers === totalJobs`. The `fake()` helper was hoisted to module scope for reuse.

### WR-01: Pinning an unstaffed sector is sticky-zero — it can never regain workers

**Files modified:** `src/sim/runner.ts`, `tests/unit/labor-sectors.test.ts`
**Commit:** `1709d30`
**Applied fix:** The leftover pool now allocates over ALL sectors in priority order after the pinned reserve pass (pinned sectors included — `s.assigned += min(needed - assigned, remaining)`), so pinning is a guaranteed floor, never an upper cap: a sector pinned while unstaffed regains workers up to `needed` once the pool grows, while existing reserves are never reduced (the pass only adds to remaining demand). The now-unused `allocateWorkers` import was removed. Added a regression test pinning commerce while the pool is empty, then growing the pool and asserting commerce regains `needed` staffing. The existing pinned-reserve test (prior staffing kept under a shrunken pool, culture starves) still passes unchanged. (Also rewrote the IN-02 comment, see below.)

### WR-02: `residentCount` and `residentsByClass` disagree after famine emigration

**Files modified:** `src/sim/runner.ts`

Healthy cities are unaffected (residents arrays are full until famine emigration); the existing determinism tests (`residentCount` round-trip and the healthy-city consistency assert) still pass.
