## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `getLaborSectors()` reported `assigned: 0` always (in-flight 19.1-03-01 work)**
- **Found during:** 19.1-03-01 (resume assessment)
- **Issue:** The in-flight implementation built fresh `LaborSector`s via `buildLaborSectors` and read `s.assigned` — which starts at 0 on every call — so `getLaborSectors()` never showed real staffing.
- **Fix:** `getLaborSectors()` reads `assigned` from the runner's `laborSectorAssigned` per-sector store (populated by `tickLabor` each tick).
- **Files modified:** src/sim/runner.ts
- **Commit:** 51c4720

**2. [Rule 1 - Bug] In-flight `CATEGORY_SECTOR` map mis-bucketed granary/market into commerce (test-pinned mapping is type-level)**
- **Found during:** 19.1-03-01 (scaffold expectations `granary→utility`, `market→utility`, `warehouse→commerce`, `theatre→culture`)
- **Issue:** A pure BUILDINGS-category map cannot split the `storage` category (granary→utility vs warehouse→commerce); the in-flight map bucketed granary+market into commerce, starving the utility sector and breaking the exact test-pinned sector rows.
- **Fix:** Replaced with an explicit `TYPE_SECTOR` map covering every type with workers (documented in labor.ts), satisfying the pinned splits.
- **Files modified:** src/sim/labor.ts
- **Commit:** 51c4720

**3. [Rule 1 - Bug] labor-sectors SaveCommand round-trip test could not round-trip staffed industry (mid-run-command replay property)**
- **Found during:** 19.1-03-02
- **Issue:** The scaffold drove `laborConnected` via test-only direct mutation (not a command), so the loaded runner had no labor connectivity; the full-array equality also diverged because the pin commands were issued mid-run (the documented pre-existing property that replay applies all commands at tick 0 — same class as the population-determinism demolish note).
- **Fix:** Rewrote the round-trip to (a) pass the town's map to `fromSaveData` (mirroring `population-determinism.ts`'s `foodChainMap()` precedent) and (b) issue the pin/pause commands BEFORE the tick window so both runs share one command timeline.
- **Files modified:** tests/unit/labor-sectors.test.ts
