## Summary

Security audit of Phase 19.1 (population-labor) against the STRIDE threat register in 19.1-PLAN.md `<threat_model>` (6 threats: T-19.1-01..05 mitigate + T-19.1-SC accept). Every declared mitigation was located in the implemented code and its boundary placement confirmed:

- **setLaborSectorState validation** is double-layered: the runner handler returns `{ok:false, error:'unknown-sector'|'invalid-config'}` (never a throw), and `validateCommand` in saveCodec.ts rejects non-string sector / non-boolean flags as `'malformed-command'` **before** `fromSaveData` replay at both load gates (save.ts, MainScene.ts). Unknown kinds fall to `'unknown-command-kind'`; `applyCommand` keeps its exhaustive `never` guard as the last-resort net.
- **Determinism integrity** holds: residency/migration mutate only inside `tick()` at `tickCount % 40` right after `tickHousingMerge`; sector config only in the command handler; all getters read-only. Proven by population-determinism byte-identity + chunked 1/7/50 + migration-refill round-trips (9 tests, green).
- **UI strings** compose from getters via `appendRow` (createElement + textContent — never innerHTML); `residenceInspection` appends resident fields only when internals carry a live cohort (old shape preserved); advisor wage/unemployment rows are guarded total functions over `population === 0`.
- **Golden byte-identity** holds: `toBuildingState`/`toWalkerState`/`getState` are whitelist copies that never serialize `residents`/`nextResidentId`/sector config; `getStateJson` = `JSON.stringify(getState())`; `git status --porcelain tests/golden` empty.
- **No-wall-clock** holds: the only `Date.now()` in src/sim/runner.ts is the `getSaveData` `savedAt` metadata line; the source-audit test enforces the rule over src/sim/{population,labor,runner}.ts (runner allowed the savedAt exception only).
- **Accepted risk** (T-19.1-SC): no external packages installed — `git diff` of the phase commit range shows zero package.json/package-lock changes; no new dependency surface.
