<objective>
Close the two runner/model gaps RESEARCH found for MARK-02 and MARK-01:
(1) per-market configuration is **stored nowhere and honored nowhere at runtime**
— `SimRunner` never references `MarketConfig`, and `targetStock` /
`buyerRadius`(config) / `preferredSupplier` are dead fields (no production
consumer; walkers hardcode `marketFoodState`, walkers.ts:372-382). Add an
**additive per-market config registry** on the runner (`setMarketConfig` /
`marketConfig`, defaulting to `defaultMarketConfig()`) plus an additive model
surface (`marketNeedsRestock` honoring `targetStock`; `findSupplier` honoring an
optional `preferredSupplier`), and thread the config to walkers via an optional
`SimInternals.marketConfig(id)` hook so it is honored **only when explicitly
set** — unconfigured markets keep today's exact behavior (decision 4 +
decisions 3's dead-field honoring, MARK-02). (2) The buyer→market→seller→house
chain is covered only through a hand-rolled walker stub
(food-slice.test.ts:120-192) — no runner-integrated test drives the chain
against the actual `SimRunner` state while `food-chain.test.ts` uses the legacy
wheat-only market walker (decision 2, MARK-01). Add a runner-integrated chain
test (`tests/integration/market-chain.test.ts`) that reserves-at-departure,
deposits-on-completion, composes a seller load, delivers to adjacent houses, and
records coverage, with the no-double-pick subset re-proven across the chain.

<threat_model>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Per-market config storage → runner state | A configured market must persist its config per-building and yield the default when unset; no unconfigured market may observe changed behavior |
| Runtime config honoring → buyer behavior | An explicitly-configured radius, refused product, or target stock must change the buyer's fetch; the unconfigured path must stay byte-identical |
| Chain deposit → market inventory | Buyer cargo must land in the market only on deposit (no teleport), the seller load must be deducted from the market, and no product may be lost or double-picked |
